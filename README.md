# soc-lab-nids-suricata-zeek-splunk-grafana
Isolated VMware lab for network intrusion detection:
Suricata (signatures) and Zeek (metadata), centralized in Splunk and shown in Grafana.
All attacks are simulated from Kali Linux only inside the isolated lab.
